## 專案簡介
本專案開發了一款具備完整媒體控制邏輯與直覺式操作介面的 MediaPlayer 播放器。本程式不僅支援標準的音訊播放功能，還內建了「安全操作機制」與「控制狀態連動」，透過彈窗確認與按鈕狀態切換，確保使用者在享受音樂時擁有流暢且穩定的體驗。

## 執行說明書與結果判讀

### 操作流程說明
請依序執行以下步驟進行媒體操作：
1. **載入媒體**：點擊「瀏覽」按鈕，系統會跳出檔案選取視窗，請選擇欲播放的媒體檔案（如 .wav 或音訊格式）。
2. **啟動播放**：成功載入路徑後，點擊「播放」按鈕，系統將初始化音訊引擎並開始輸出聲音。
3. **播放控制**：在播放過程中，可點擊「暫停」保留進度，或點擊「停止」結束目前音軌。
4. **安全結束**：若欲關閉程式，點擊視窗關閉鈕時系統會彈出確認視窗，避免誤觸導致工作進度遺失。

### 功能按鈕
* **瀏覽**：呼叫系統 `OpenFileDialog` 視窗，協助使用者選取指定路徑並載入媒體資源。
* **播放**：啟動音訊播放執行緒，並將播放進度置於作用中。
* **暫停**：凍結當前播放進度，再次點擊可從原位置恢復播放。
* **停止**：終止播放行為並將音訊進度重置至起始位置。
* **確認關閉**：攔截視窗關閉事件，觸發確認對話框以確保操作意圖。
